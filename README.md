\# 🏍️ Bike Resale Value Prediction



A machine learning web application that predicts the estimated resale value of a used bike based on its details.



\## Features



\- Bike brand and model selection

\- Engine capacity selection

\- Bike age and kilometers driven

\- Number of previous owners

\- Bike condition

\- Launch price

\- Machine learning based resale-value prediction

\- Depreciation visualization

\- Dynamic bike image after analysis
